# PTP Demo Network Setup

## About

The **PTP Demo Network Setup** package creates a ready-to-use sample environment for learning, demonstrating, and exploring PTP monitoring in DataMiner.

It deploys a realistic multi-site timing network across several locations, so teams can immediately review clock relationships, connectivity, and end-to-end synchronization behavior without first building a lab from scratch.

This makes it a practical starting point for demos, workshops, training sessions, and validation exercises around PTP visibility in DataMiner.

## Key Features

- **Ready-made sample environment**: Quickly deploy a complete PTP demo network instead of manually creating each device and link.
- **Realistic network layout**: Explore a distributed setup with multiple locations, interconnected switches, and different clock roles.
- **Clear topology experience**: Review how connectivity and clock relationships appear in DataMiner on a richer, more representative network.
- **Learning-focused setup**: Use the package as a safe environment for onboarding, testing, and hands-on exploration of PTP behavior.
- **Multi-domain scenario coverage**: Work with both production and test timing domains in one prepared environment.

## Use Cases

- **Product demonstrations**: Show the value of PTP monitoring in DataMiner without relying on live infrastructure.
- **Training and onboarding**: Help operators and engineers get familiar with PTP concepts and topology views in a guided sample setup.
- **Feature validation**: Test visualization, connectivity, and monitoring workflows against a realistic demo network.
